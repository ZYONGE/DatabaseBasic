## Project Overview
**Course:** Database  
**University:** Tech University of Korea (TUK)

This repository contains SQL practice code written while studying Database.

The purpose of this project is to:

- practice core concepts of Database
- organize lecture exercises
- build a structured learning record

Lecture code is organized **by SQL command type** — one file per command (`SELECT.sql`, `INSERT.sql`, `UPDATE.sql`, `DELETE.sql`, `CREATE.sql`, `ALTER.sql`, `DROP.sql`).
Each file starts with a table of contents, and every section notes which lecture / textbook section it came from.
Every statement has a `-- [키워드]` comment above it explaining its syntax and what it does.

## Getting Started

All scripts target **Oracle Database** and can be run with SQL*Plus or Oracle SQL Developer.

```bash
# 1) 관리자 계정으로 실습용 사용자 생성
sqlplus system/<password>@<host>:<port>/<service> @setup/01_create_user.sql

# 2) 생성한 사용자로 접속해 샘플 테이블·데이터 구성
sqlplus KIM/bluesky@<host>:<port>/<service> @setup/02_sample_data.sql

# 3) 결과 확인
sqlplus KIM/bluesky@<host>:<port>/<service> @setup/03_check.sql
```

After setup, open any command file (e.g. `SELECT.sql`) and run statements one at a time.

> **Note**
> - Lines marked `[형식]` are syntax templates from the textbook and are not executable as-is.
> - Some examples use standard SQL that Oracle does not support (e.g. `CREATE ASSERTION`, `AS` for table aliases). These are noted in the comments.
> - Several files redefine `EMPLOYEE` / `DEPARTMENT` for illustration — run them in a separate schema or drop the existing tables first.
